# Mobile Header Information Display

简体中文 | [English](README.md)

在 Obsidian 移动端顶部栏区域显示当前笔记的元信息。
（当前最低支持的 Obsidian 版本为 `1.5.0`）

## 功能

- 在移动端顶部栏显示当前笔记路径、创建时间和修改时间。
- 每条信息纵向排列；当单行内容超过可用宽度时，支持横向滑动查看。

## 安装

### BRAT 安装 （推荐）

适用于仓库发布到 GitHub 后通过 BRAT 安装：

1. 在 Obsidian 中安装并启用 `BRAT`。
2. 打开 `BRAT` 设置，选择添加 Beta 插件。
3. 输入当前仓库的 GitHub 地址。
4. 安装完成后，在社区插件列表中启用本插件。

如果当前仓库尚未发布到 GitHub，建议使用手动安装。

### 手动安装

1. 下载 `manifest.json`、`main.js`和`styles.css` 
2. 复制到以下目录：
/.obsidian/plugins/mobile-header-information-display/
