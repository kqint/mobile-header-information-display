# Mobile Header Information Display

[简体中文](README.zh-CN.md) | English

Display current note metadata in the Obsidian mobile header area.
(`1.5.0` is the current minimum supported Obsidian version.)

<img src="assets/demo.jpg" width="300" />

## Features

- Display the current note path, creation time, and modification time in the mobile header.
- Each item is arranged vertically; when a single line exceeds the available width, horizontal scrolling is supported.

## Installation

### Install with BRAT (Recommended)

This applies after the repository is published to GitHub and installed through BRAT:

1. Install and enable `BRAT` in Obsidian.
2. Open the `BRAT` settings and choose to add a beta plugin.
3. Enter the GitHub repository URL for this project.
4. After installation, enable this plugin in the Community Plugins list.


### Manual installation

1. Download `manifest.json`, `main.js`, and `styles.css`.
2. Copy them to:
   `/.obsidian/plugins/mobile-header-information-display/`
